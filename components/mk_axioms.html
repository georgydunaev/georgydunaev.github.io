Morse–Kelley Class Theory

Class-Theoretic Axiomatics in Obelisk

Unlike ZFC which treats sets as the only objects, Obelisk formalizes impredicative class comprehension (Item 3.01): classes can be proper classes or sets. Sethood is defined by isSet(X) ⇔ ∃ Y. X ∈ Y. The system subsumes NBG and ZFC with higher consistency strength.
