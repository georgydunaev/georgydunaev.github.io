Core Projects

Proof Assistant & Foundations

Obelisk Proof Assistant ↗

An interactive LCF-style proof assistant designed for Morse–Kelley class theory with higher-order logic features. Emphasizes zero implicit computation, transparent verifiable syntactic trees, and an ultra-small trusted kernel in Standard ML (Poly/ML). Includes an innovative class-level tagged pairing mechanism and an abstract layer atop CakeML.

Recursion Theorem in ZF (AFP) ↗

Formalized and machine-checked proof of the classical Recursion Theorem following Hrbacek and Jech, published in the Archive of Formal Proofs (Isabelle/ZF). Models Peano arithmetic in axiomatic set theory and verifies primitive recursive functions with absolute rigor.
